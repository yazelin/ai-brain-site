這一層放的是格莉奇的插畫與場景圖。**規格級的圖不在這裡**，在上一層：

| | 檔案 | 內容 |
|---|---|---|
| Outfit A 正典 | `images/glitch-ref.webp` | 三視圖。長帽 T ＋裸腿，沒有裙子 |
| Outfit B 正典 | `images/pet*.webp` 那五張立繪 | 裙＋斜背包＋單邊過膝襪＋腿套 |

翻到的必須是唯一那一張；插畫跟規格混在同一層，下一個人分不出哪張說了算。
